<objective>
Put Scratchpad's memo autosave on the shared `src/lib/debouncedSave.ts` helper and
make its unmount perform the pending save (D-01), through a small hook that every
autosave surface will reuse.

Purpose: `ScratchpadPane.tsx:541-545` only cancels its 700 ms timer on unmount, so
an edit typed just before the pane closes is lost (research Pitfall 1). The shared
helper already has `schedule`/`flush`/`cancel` and a serializing `SaveQueue`; it
gains a settle result so teardown code can tell clean, saved, and failed apart,
and a failed value stays pending so a later retry has something to retry.

`src/lib/teardownSave.ts` hook with a registry of mounted savers (the quit flush in
09-08 walks it), and the Scratchpad conversion with tests.
