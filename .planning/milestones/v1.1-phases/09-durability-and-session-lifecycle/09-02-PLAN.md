<objective>
Make a SIGHUP-trapping terminal child killable (REL-01) with a timeout-gated,
process-group-targeted escalation ladder, and clean up every terminal child at app
exit (D-12).

Purpose: today `TerminalSession.killer` is the `ProcessSignaller` returned by
`child.clone_killer()`, whose `kill()` is one bare SIGHUP to one pid with no retry
(research Pattern 3, verified in portable-pty 0.8.1 source). The terminal child is
already its own session and process-group leader because portable-pty calls
`setsid()` in `pre_exec` (research Pattern 2), so the child's pid is its pgid and
`kill(-pid, sig)` reaches exactly its own group. No new crate: the raw
`extern "C" { fn kill(pid: i32, signal: i32) -> i32; }` idiom already lives in
`src-tauri/src/command_output.rs:542-568`.

Output: escalation ladder and quit sweep in `src-tauri/src/terminal/mod.rs`, one
exit-arm call in `src-tauri/src/lib.rs`, real-PTY `phase09_02` tests, and the
terminal_kill evidence text refreshed.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview -> Rust IPC (`terminal_kill`) | The frontend supplies a session handle; the backend decides which OS processes receive signals |
| Maru process -> OS process table | `kill(-pgid, sig)` affects every process in the group, including processes the user launched inside the terminal |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-02-01 | Tampering | `terminal_kill` signal target | high | mitigate | Signal only `-pgid` where pgid is the session's own spawn-time `child.process_id()` (== pgid via portable-pty `setsid`); never a pid from the request, never the session id as a whole; handle is re-validated by `get_session_generation` first |
| T-09-02-02 | Denial of Service | SIGHUP-immortal session | medium | mitigate | Timeout-gated ladder SIGHUP -> 2 s -> SIGTERM -> 2 s -> SIGKILL on a detached thread; quit sweep SIGKILLs any survivor before exit |
| T-09-02-03 | Tampering | pgid reuse after the group dies | low | accept | Liveness is re-probed before every signal (50 ms poll) and the ladder stops once the group is gone; residual window is one poll interval |
| T-09-02-04 | Elevation of Privilege | stale frontend handle killing a recycled session | medium | mitigate | Existing generation-token validation unchanged; test (c) pins that the old-generation handle is rejected after respawn |
| T-09-02-05 | Denial of Service | lock held across sleeps blocking other terminal commands | medium | mitigate | Escalation thread and sweep polling hold no session, registry, killer, or escalation lock while sleeping; tested by concurrent spawn/kill under 1 s |
| T-09-02-SC | Tampering | package installs | low | accept | No new crate: raw `extern "C" kill` idiom reused from command_output.rs; package legitimacy gate not triggered |
