### Integration Findings

1. **Warning (REL-03, PERF-04, PERF-06): recovery writes cause watcher churn.**
   - `relevant_path` in `src-tauri/src/vault_watcher.rs` does not exclude
     `.maru/recovery`.
   - Each recovery copy keeps its document extension, so every teardown or
     quit recovery write emits a `VaultIndexDeltaEvent`.
   - The index is not affected, because the rescan skips dot directories.
   - This is not a blocker: PERF-04 as written covers `GENERATED_DIRS`, and
     no data is lost.
   - The fix is to add `.maru/recovery` to the exclusion arm. The team lead
     is landing it in a small PR.
2. **Info (TEST-01): menu.spec terminal.split failed once.**
   - The failure was "terminal.shell then terminal.split produces a second
     terminal pane" on main run 36285382993 (8fd66232).
   - The spec passed in the seven main runs before it and on the next run,
     36286207160.
   - The code has not changed since PR #50, so this is a pre-existing flake.
     It is tracked on #388 together with the pty.spec flake.
