<objective>
Stop all five recursive filesystem watchers from emitting events for paths under
the shared `GENERATED_DIRS` prune list, by adding one root-agnostic predicate in
`paths.rs` (the Phase 2 SSOT home of the list) and referencing it at each
watcher's per-path dispatch filter.

Purpose: today no watcher module references `GENERATED_DIRS` at all, so a watched
root that gains a heavy generated subtree (an ops_catalog business unit that
grows `node_modules`, a vault that gains `target/`) floods the debounce/drain
pipeline with events the frontend can never act on. CONCERNS.md §3 names this;
the per-BU ops_catalog growth is the motivating case. Dispatch-time filtering per
D-04 (not registration-time exclusion) so directories created after registration
are pruned too.

Output: `paths::is_under_generated_dir` with colocated tests, and the predicate
referenced at all five watcher sites with the existing per-path filter shape
extended. Implements D-04, D-05, D-06.
</objective>
