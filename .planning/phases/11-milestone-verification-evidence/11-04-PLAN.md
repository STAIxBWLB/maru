## How each task runs the validate-phase workflow

This applies to all three tasks, with NN being the phase.

1. Run `gsd_run query init.phase-op NN`. It must resolve `phase_dir` under
   `.planning/milestones/v1.0-phases/`, which was confirmed for 02 at planning time.
   This is State A, because the VALIDATION.md exists.
2. Step 2, discovery. Read NN-VALIDATION.md and NN-VERIFICATION.md in full. From each
   NN-*-PLAN.md and NN-*-SUMMARY.md, read only the frontmatter (`requirements`,
   `key-files`) and the task names, using grep on `<name>` and `## Task`. Do not read
   whole bodies; context budget matters, since phase 01 alone is about 60k tokens of
   archive text.
3. Step 3, gap analysis. Run every row's automated command fresh now and classify each
   requirement COVERED, PARTIAL or MISSING. For cargo filters, a `running 0 tests` line
   means the filter matched nothing, which is PARTIAL, never green.
4. Step 4's user gate is pre-answered by D-09:
   - A unit-testable MISSING or PARTIAL row gets a small test (step 5, done inline by the
     executor).
   - A gate-behavior row proven by break-and-revert is `manual-only`, citing the recorded
     evidence file.
5. Step 6, State A update:
   - Frontmatter: `status: validated`, `nyquist_compliant` from the result,
     `wave_0_complete: true`.
   - Per-Task Verification Map: real task IDs and plan IDs in place of `TBD`. The
     `File Exists` cell becomes `Yes`, and the `Status` cell becomes `green` or
     `manual-only`, the vocabulary of the validated 04-VALIDATION.md exemplar. Keep each
     file's existing column set exactly.
   - Wave 0 checkboxes ticked where the artifact now exists.
   - Manual-Only table and Sign-Off updated, `**Approval:** validated 2026-09-25`.
   - Append `## Validation Audit 2026-09-25`: the Gaps found / Resolved / Escalated
     table, followed by bullets with the commands run, their test counts, and
     `git rev-parse --short HEAD`.
6. Skip the workflow's own step 7 commit. Commit per task through the executor's normal
   protocol.
7. All new or edited text uses ASCII punctuation (no em-dash, curly quotes or ellipsis).
   The ascii-lint hook rejects them. Leave untouched legacy lines as they are.
