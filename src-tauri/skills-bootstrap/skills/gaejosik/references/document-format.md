# 개조식 문서 구조와 마크다운 소스 규칙

## 문서 구조 가이드

개조식 문서의 일반적 구조 패턴.

### 항목 나열형

```
1. 추진 배경
   - 지역 AI 인력 수요 지속 증가
   - 기존 교육과정과 산업 요구 간 괴리 존재
   - 국가 차원의 AI 인재 양성 정책 강화 추세

2. 주요 내용
   - AI 교육 플랫폼 구축: Saltlux LUXIA LLM 기반 개인화 학습 시스템
   - 산학협력 체계: 연세대, KAIST 공동 연구 및 커리큘럼 개발
   - 성과 지표: 수료율 90% 이상, 취업 연계율 70% 목표
```

### 분석 보고형

`□`·`○` 줄은 각각 독립 단락(앞뒤 빈 줄), 세부는 마크다운 리스트로 붙이는 하이브리드 형태.
(소스 규칙은 아래 「마크다운 작성 규칙」)

```
□ 현황

  ○ 전년 대비 AI 관련 취업자 수 23% 증가

  ○ 지역 내 AI 스타트업 12개 신규 설립
  - 창업 3년 미만 9개, 후속 투자 유치 4개
    - 시드 3개, 프리A 1개

  ○ 교육 프로그램 수료자 누적 150명 돌파

□ 문제점

  ○ 고급 인력 수도권 유출 지속

  ○ 실습 인프라 노후화로 실무 교육 한계

□ 개선 방안

  ○ regional innovation 사업 연계 인프라 현대화 추진

  ○ 기업 맞춤형 단기 부트캠프 확대
  - 수요조사 기반 4주 과정 3종 신설
```

## 마크다운 작성 규칙 (기호 사다리·줄바꿈·들여쓰기)

개조식 본문을 마크다운으로 쓸 때의 소스 규칙. 작업공간에 별도 서식 SSOT가 있으면 그것이 우선.

### 기호 사다리 (본문 4단)

| 단 | 기호 | 마크다운 소스 표기 | 비고 |
|----|------|-------------------|------|
| 1 | `□` U+25A1 | `□ 내용` (들여쓰기 0) | 독립 단락 |
| 2 | `○` U+25CB | `  ○ 내용` (2칸) | 독립 단락 |
| 3 | `-` | `- 내용` | 마크다운 리스트 항목 |
| 4 | `·` U+00B7 | `  - 내용` (중첩 리스트) | 소스는 `-`, 컨버터가 `·` 출력 |

- 2단 원은 `○`(U+25CB)만 사용. `◦`(U+25E6)·ASCII `o`·`ㅇ`(U+3147)·`❍`(U+2755) 금지.
- 1단 사각은 `□`(U+25A1)만 사용. `◾`(U+25FE) 등 채워진 변형 금지.
- `□ (라벨) 내용` 형태의 괄호 라벨 관용구 허용.
- `※`(참고), `*`(부기)는 사다리 밖 보조 기호로 유지.

### 줄바꿈 규칙

- `□`·`○` 줄은 독립 단락: **앞뒤로 빈 줄 필수**.
- `-` 줄은 진짜 마크다운 리스트 항목. 연속 항목 사이 빈 줄 불요. 바로 위 `○` 단락에 빈 줄 없이 이어 붙여도 됨(리스트는 단락을 중단할 수 있음).
- 4단은 중첩 리스트 `  - 내용`으로 작성. 컨버터가 `·` 글리프로 출력.
- 소스 들여쓰기 3칸 이하 (빈 줄 뒤 4칸 이상은 코드블록으로 해석). 권장: `□` 0칸, `○` 2칸, `-` 2칸.
- 금지: 행말 공백 2칸(하드 브레이크), 본문 산문 내 `<br>`, 행말 역슬래시.
- 컨버터는 소스 들여쓰기가 아니라 **기호로** 단을 판정. 들여쓰기는 사람이 읽기 위한 장치.
- 코드펜스 안의 예시·템플릿은 예외.

**잘못된 예** (단일 줄바꿈에 의존):

```
□ 현황
  ○ 전년 대비 AI 관련 취업자 수 23% 증가
  ○ 지역 내 AI 스타트업 12개 신규 설립
```

렌더·docx 결과는 세 줄이 한 단락으로 붕괴:
`□ 현황 ○ 전년 대비 AI 관련 취업자 수 23% 증가 ○ 지역 내 AI 스타트업 12개 신규 설립`

**올바른 예** (정본):

```
□ (비전) 글로벌 수준의 인재양성 플랫폼 구축

  ○ 혁신가 커뮤니티 조성 지향

  ○ 오류 내용
  - 각주 3개 값이 재배분 이전 수치
    - 논문 8건, 특허 출원 9건
```

### 제목 번호

번호는 마크다운 소스에 **리터럴로 기재**.

- `# 문서 제목`(번호 없음) → `## Ⅰ. 대항목` → `### 1. 중항목` → `#### 가. 소항목` → `##### 1) 세항목`
- `Ⅰ`은 전각 로마자(U+2160 계열). ASCII `I.` 금지.
- 컨버터는 리터럴 번호가 있는 제목에 자동 번호를 덧붙이지 않음.

### HWPX 출력 계약

HWPX 공문서 출력은 separate wrapper가 아니라 released `hwp` 스킬(minimum `v1.2.0`)로
처리한다. 정확한 번호·프로필·제한 사항은 설치/export된 tree의
[`skills/hwp/references/korean-official-format.md`](https://github.com/STAIxBWLB/agent-hwp/blob/v1.2.0/skills/hwp/references/korean-official-format.md)와
[`skills/hwp/references/editing-recipes.md`](https://github.com/STAIxBWLB/agent-hwp/blob/v1.2.0/skills/hwp/references/editing-recipes.md)를 따른다.
이 스킬은 마크다운 작성 규칙의 SSOT이며, 출력 엔진의 세부 결과를 별도로 약속하지 않는다.
